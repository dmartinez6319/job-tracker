## how I used AI ##
- Helped guide me on project structure and organization
- helped me reformat my code and make it way easier to read
- Helped me debug errors that I couldnt solve initially on my own
- Explained certain python functions that I was unfamiliar with to solve a problem
- Guided me in using flask to build a backend with python
- Provided terminal commands to help speed up my development process instead of searching through docs
- Reviewed code that I wrote and suggested improvements and explaination on their usefulness
- Helped me understand best practices to follow while developing the project

- "How should I structure and organize my Flask project?"

## Lessons Learned

- AI can make mistakes so its important to test the code
- Sometimes AI makes code more complicated than it needs to be
- Asking ai to explain things helped me learn faster
- Keeping code organized makes it easier to debug
- AI is useful for saving time but its still important to understand what the code does
